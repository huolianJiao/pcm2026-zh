# 公开发布风险核查（2026-09-27）

结论：存在官方要求停止分发、警告或提交平台下架投诉的风险。无法预测Nacon是否会针对这个项目采取行动，不能因为免费、标注非官方或提供MIT源码就认定获得授权。本页是发布风险梳理，不替代针对适用法和具体发布方式的法律意见。

## 游戏条款

从[PCM26官方Steam商店页](https://store.steampowered.com/app/3936530/?l=english)链接进入的[游戏EULA](https://store.steampowered.com//eula/3936530_eula_0)：

- 第1、2节：个人使用许可不转移游戏及其组成部分的知识产权。
- 第3节第4项：限制修改组成部分及创作衍生作品。
- 第3节第7项及后续段落：限制传播游戏及其组成部分。
- 第3节第8项：限制逆向、反汇编、反编译。
- 第3节明确保留适用法强制规定和Nacon授权的例外，因此条款本身不能替代具体法律判断。
- 第9节确实涉及用户生成内容，但没有明确写明允许修改／分发这个DLL；不能据此推定所有技术路线的mod都获准。

本汉化确实修改游戏DLL、打包派生语言数据库和字形资源。发布完整修改后DLL和覆盖pak，比只发布自编工具更直接涉及游戏组成部分的传播。中文译文也可能涉及对原游戏文本的翻译／衍生作品权利，不能简单宣称译文整体完全独立于游戏权利。

## 字体：当前本地预览产物不能视为已获分发许可

当前验证过的本地构建使用 Microsoft YaHei UI 逐字生成图集。[微软字体许可FAQ](https://learn.microsoft.com/en-us/typography/fonts/font-faq)区分整句图片与可复用的逐字位图字体，并明确不因转换格式而放宽嵌入和再分发限制。因此“没有附带ttf”不足以排除这项风险，此前只关注字体文件本身的说明不完整。

建议发布前改为允许嵌入和再分发的开源字体，保留其许可和署名，例如采用SIL OFL的[Noto CJK Sans](https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/LICENSE)。换字体后还需重新构建和验证排版，不能仅替换许可证文字。

## 建议的发布方式

1. 向Nacon/Cyanide说明免费中文汉化、所改文件、安装方法、是否分发DLL／资源，请求书面确认许可范围。
2. 将完整游戏DLL改为差分或本地应用修改；尽可能不分发原游戏数据库及原图集。用户从自己合法安装中生成所需文件。
3. 使用许可明确的开源字体，保留版权和许可证。
4. MIT只覆盖原创代码；不要给游戏资源、原文或字体重新授予MIT。
5. 标注非官方，不使用官方背书措辞，不捆绑游戏本体、破解或DRM绕过。免责声明本身不是授权。

差分补丁和本地构建只能减少直接复制分发游戏资源，不自动解决修改条款、翻译权或其他权利问题。

GitHub有[DMCA下架流程](https://docs.github.com/en/site-policy/content-removal-policies/dmca-takedown-policy)，上传成功不代表内容已被认定合法。官方是否警告、是否采取账户措施或法律行动无法据此量化。本项目没有验证联网环境或反作弊兼容性，也不承诺不封号。

公开发布的技术准备和风险决定不等于取得官方授权；本项目未声称获得Nacon许可。
