# PCM26 简体中文汉化

Pro Cycling Manager 2026 非官方简体中文补丁，当前版本 **v0.5.0-preview**。仅替换 **Dansk（丹麦语）**，英语保留原文。

非官方项目，许可范围与已知分发风险见[发布风险核查](docs/RIGHTS_REVIEW.md)。本版新增事务日志、失败回滚和中断恢复，仍为预览版。

## 普通玩家安装

1. 在本仓库 Releases 下载 **PCM26-ZH-v0.5.0-preview.zip**，不要下载 GitHub 自动生成的 Source code ZIP。
2. 保存进度并退出游戏。Steam 更新后旧汉化变成问号时，请使用下方的 Repair.cmd 流程；其他汉化请按其原安装说明处理。
3. 把 ZIP 完整解压到一个独立目录。不要直接在压缩软件里运行，也不必复制到游戏目录。
4. 双击 **Install.cmd**。检测到 Steam 游戏目录后，输入 Y 确认；未找到时粘贴自己的游戏安装目录，例如 `D:\SteamLibrary\steamapps\common\Pro Cycling Manager 2026`。
5. 看到 `Installed` 提示后启动游戏，在语言设置中选择 **Dansk / Danish / 丹麦语**。如果界面没有立即变化，退出并重新启动游戏。
6. 双击 **Check.cmd** 可核对安装文件和原版备份；卸载用 **Uninstall.cmd**。意外退出后先运行 **Recover.cmd**，再启动游戏。

普通玩家不需要 Python、Git、Oodle 或编译工具。仅当安装目录没有写入权限时，才需要右键 Install.cmd 以管理员身份运行。

完整说明：[安装、卸载与恢复](docs/INSTALL.md)。

## Steam 更新后修复汉化（玩家）

Steam 更新可能覆盖字体补丁 DLL，但留下汉化 pak，导致中文显示问号。**不要将旧版 DLL 复制回新版游戏，也不要跳过版本检查。**

1. 保存进度并退出游戏，检查本页的兼容 Steam Build。本版只适配 **25503277**。
2. 从 [Releases](https://github.com/huolianJiao/pcm2026-zh/releases) 下载匹配版本的安装 ZIP，完整解压到独立目录。
3. 如果是更新后残留本项目旧汉化，双击 **Repair.cmd**，确认游戏根目录。首次安装使用 **Install.cmd**。
4. 修复器核对新版原 DLL 和已知旧汉化包的哈希，将旧包保存到 `PCM26-ZH-Backup-25503277/update-*/previous-overlay.pak`，备份新版原 DLL，再安装新版补丁。遇到未知文件会停止。
5. 双击 **Check.cmd**。成功后启动游戏，语言选择 **Dansk（丹麦语）**；英语保持原文。
6. 卸载本版使用本版 **Uninstall.cmd**，恢复的是新版原 DLL；安装意外中断先运行 **Recover.cmd**。保留所有备份目录，不要用旧版卸载器覆盖新版游戏。

如果 Steam 再次更新至其他 Build，等待对应适配版本。需要先恢复游戏时，将汉化 pak 移到游戏目录外保存，再在 Steam 验证游戏文件；不要强行恢复旧 DLL。本补丁不修改存档。

## 新游戏版本的汉化适配流程（维护者）

1. 记录 Steam Build，保留新原版 DLL、PDB 和资源的只读副本及 SHA256；不要将游戏资源提交到源码仓库。
2. 比较字体资源及两份语言数据库。按 ID、文本键和英文源文哈希迁移译文，补译新增或变化的条目；保留变量、换行和链接格式。继续使用经理模式、数字月份和统一洲际赛事术语。
3. 使用新版符号与反汇编定位字体相关函数，比较控制流、指令和跳转表。确认补丁位置及原始字节后更新 DLL 哈希白名单和适配代码，不能只修改版本号或跳过断言。
4. 更新 `resources.json`、`translations/zh-CN.json`、构建兼容配置和独立的新版本备份目录；仅加入经过验证的旧覆盖包哈希供 Repair 使用。
5. 按 [源码构建说明](docs/BUILD.md) 在独立目录构建。核对中文字形覆盖、pak 回读、两份数据库所有非丹麦语列保持原版，以及 DLL 补丁完整性。
6. 运行 `python -m unittest discover -s tests -v`，测试安装、重复安装、卸载、失败回滚、中断恢复和旧包修复。用 `tools/verify_release.py` 检查最终 ZIP，并在隔离目录测试真实发行载荷。
7. 游戏内检查中文菜单、长段落、比赛界面和所需分辨率，记录已验证范围与未验证项目。更新 README、CHANGELOG 和发布说明，按 [发布流程](docs/RELEASING.md) 生成新版本包并发布预览 Release。

版本适配需要重新分析游戏二进制，目前不能自动保证兼容未来更新。
